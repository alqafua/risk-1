# شوقا | Choga

الموقع التعريفي (صفحة نبذة) لمتجر **شوقا (Choga)** اليمني المتخصص بصناعة الشوكولاتة الفاخرة، تأسس عام 2024 في صنعاء.

- إنستغرام: https://www.instagram.com/choga.yo
- واتساب: +967 781 890 601

## التشغيل محليًا

```bash
pip install -r requirements.txt
python app.py
```

يفتح الموقع على `http://localhost:8000`.

## النشر

المشروع جاهز للنشر على Railway مباشرة (يحتوي `Procfile` و`requirements.txt`).
