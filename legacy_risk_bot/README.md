# Risk Guard 🛡️

أداة إدارة مخاطر كاملة لتداولك اليدوي على Binance Futures:
- 26 قاعدة حماية ذكية
- سحب الربح تلقائي لحساب آخر
- لوحة تحكم ويب
- إشعارات Telegram
- تقارير أسبوعية

## البدء السريع

1. ارفع الملفات لـ GitHub
2. أنشئ Railway Project من المستودع
3. أضف متغيرات البيئة (Environment Variables)
4. انشر المشروع

## الملفات المطلوبة

**بـ .env:**
- مفاتيح Binance API (Futures + اختياري ثاني للسحب)
- Telegram Bot Token و Chat ID
- توكنات عشوائية

## المميزات

✅ SL تلقائي على كل صفقة
✅ إدارة DCA (تعزيز) ذكية
✅ حماية من الخسائر المتتالية
✅ Cooldown إجباري بعد الخسائر
✅ سحب الربح الزائد تلقائي
✅ تقارير يومية/أسبوعية
✅ Dead Man's Switch (تنبيه إذا السكربت توقف)

## لوحة التحكم

افتح الرابط اللي يعطيك ياه Railway وسجل بالـ WEB_UI_TOKEN.

كل القواعس والأرقام قابلة للتعديل من اللوحة مباشرة، بدون إعادة تشغيل.
